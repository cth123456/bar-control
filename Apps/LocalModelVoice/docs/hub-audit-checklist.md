## 二、三处「要求 ≥N」的注解（写给你看的那句话就是这里）

### 第 1 条：池里 23 个（要求 ≥25）——差 2

- **差的 2 条点名**：`codex-router-gpt-6-astra`（模型 `gpt-6-astra`）、`codex-router-gpt-5-6-sol`（模型 `gpt-5.6-sol`）。
- **为什么没进**：它们和 TeamoRouter 收编进来的 `teamorouter-gpt-6-astra`、`teamorouter-gpt-5-6-sol` 是**同一个模型名**。收编的方案里写着「同一个模型只收编一次，跳过重复 2 条（Codex Router · GPT-6-Astra (Codex)、Codex Router · GPT-5.6-Sol (Codex)）」——**模型在池里了，只是挂在 TeamoRouter 那边**，4202 侧让位。
- **真实落点**：不是丢 2 个模型，是同 2 个模型的第二份挂靠；Agent 的调用不受影响（③ 收编后剩「内部线路 2」条就是它们，见 §三）。
- **怎么才绿**：修 Ark 连接（key + ≥4 个 plan 模型）→ 池再 +3 = **26 ≥ 25 ✅**（这条路不需要动同名筛子）。
- 不建议为了这条放宽「同名只留一条」：网关侧的理由是同名挂两遍、翻车时每次请求多等一轮。

### 第 2 条：4202 组 16 个（要求 ≥17）——差 1，**而且收编永远到不了**

- **现在**：16 = 1 条 `jev-auto` + 收编进来的 15 条内部线路（收编前是 1）。
- **全量口径**：17 条内部线路，能收的 15 条 + 同名让位 2 条 = 17；全进来才是 18（≥17 的意思就是「那 2 条至少得进来 1 条」）。
- **真实落点**：③ 收编后剩「内部线路 **2**」条，正是 §二第 1 条点名的那两条。
- **⚠ 结论**：只要「同名只留一条」在，这一项上限就是 **16**，**收多少次都过不了 17**。判据本身要改，二选一（建议 (a)）：
  - (a) 判据改成「内部线路里没进池的、又不是同名让位的 = 0」，文案写「能收的都收了」；
  - (b) 阈值改 16，注解写「17 条内部线路里 2 条同名让位给 TeamoRouter」。
  - (c) 让两条都进池 = 改产品行为（取消同名筛子），不建议（理由同上）。
- 用户版一句话：**「差的不是 1 条线路，是 2 个同名模型各自没有第二份挂靠。」**

### 第 4 条：Ark「2/3 条线路在池里」（阈值 ≥4）——这条不是收编的事

- 判定依据（收编后原文）：「依据连接 id=ark-agent-plan『Ark Agent Plan』：2/3 条线路在池里（阈值 ≥4）；api_key 在、收编台账 无记录、收编挂过的线路 1 条」。
- 那条「挂上来但没进池」的线路点名是 **`ark-agent-glm-5-3-glm-latest`**（Agent 侧，挂到已有连接、只挂线路不改连接）——**不是** §二第 1 条点的两条，两者互不相干。
- 要绿只有一条路：把 `ark-agent-plan` 的 `api_key` 换成 providers 行里那把（拿它请求 plan 端点是 200），并把 `models` 写到 ≥4 个可用名（建议 5 个：`glm-5.3`、`glm-5.3-flash`、`deepseek-v4.1-flash`、`kimi-k2.7-code`、`minimax-m3`）。这要用户拍板，见 §七。

## 五、命名演练（新连接、新分组、新行 id，三处能对上吗）

一次「全部范围」收编里，App 会起这些名字。逐条对过 ①②③，**能对上**：

| 东西 | 名字 | 命名规律 |
|---|---|---|
| 新连接 1 | `TeamoRouter（App 收编）`，id `teamorouter-app`，`source=app-adopt` | 来源名 + 「（App 收编）」；id = 来源短名 + `-app`；识别项认的就是 `source=app-adopt` |
| 新连接 2 | `4202 内部线路（App 收编）`，id `4202-app` | 同上 |
| 池内分组标签 | `TeamoRouter`、`4202 内部线路`（① 里显示短的，不带后缀） | 分组标签 = 连接名去掉后缀；列表短、池里也短，都认得出来 |
| 挂到已有连接 | 行 `ark-agent-glm-5-3-glm-latest` → 挂到 `ark-agent-plan`，**不新建连接、不改连接** | 「地址相同就只挂线路」 |
| 新行 id | `teamorouter-gpt-6-astra`、`codex-router-deepseek-v4-pro` | 来源短名 + 模型名，`/`、`.` 转成 `-` |
| 单模型连接（旧） | `Jev / 4202`（`source=jev:4202`）、行 `codex-router-jev-auto` | 历史命名，保持不动 |
| ③ 状态名 | `[可收编]`、`[Agent 侧]`、`[内部线路]`、`[已归属未进池]`、`[引用缺口]` | 每组一个按钮名，和四块台账同词 |

规律一句话：**连接名 = 来源 + 「（App 收编）」；连接 id = 来源短名 + `-app`；行 id = 来源短名 + 模型名（符号转 `-`）**。同一个东西在 ①（分组）、②（连接）、③（行）里都能按名字认出来，没有互相打架的名字。已知例外只有历史连接（`api-model-list`、`deepseek`、`Jev / 4202`），收编不会去改它们。
