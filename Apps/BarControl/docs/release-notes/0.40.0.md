# Bar Control 0.40.0

## 新增
- 发现新版本时弹窗提示，可「立即更新」「稍后」或「跳过此版本」
- 一键更新：下载 zip → SHA-256 校验 → 解压 → 代码签名校验 → 退出后替换并自动重开
- 设置里新增「关于」页：版本、检查更新、仓库链接、开源许可、复制版本信息
- 展开菜单的「Touch Bar 设置」右侧显示可更新版本

## 改进
- 自动检查更新默认开启，启动后检查，每 24 小时最多一次
- 更新检查优先读取 `docs/updates.json`，再回退 GitHub Releases Atom（不受 API 限流）、API 与 Tags
- 设置统一在同一个窗口：接口详情与让位应用默认内联展开，组件编辑器在右栏打开
- 同一版本 24 小时内最多弹一次；跳过某版本后不再提示该版本

## 说明
- 下载新版替换旧版即可，模块布局与设置会保留
