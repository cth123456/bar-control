# Bar Control 0.40.9

## 功耗与稳定性
- 空闲功耗从约 4.3% 降到约 1.6% CPU，接近 Loon 的水平。
- 菜单关闭时指标采样降到 10 秒一次，接口详情 30 秒或电源变化才扫描。
- AI 角标降到 2fps 并缓存文字尺寸；功率动画最高 8fps。
- 详情切换不再和输入法提示反复争抢；点击模块后详情优先，零宽兜底只作用于主层。

## 设置与界面
- 硬件分类不再折叠，进入后直接显示充电器、USB-C 端口、线缆和供电结论。
- 设置窗口打开时显示 Dock 图标，关闭后回到后台代理。
- 修复功率详情最右侧气泡被黑底裁切的问题。

## 电源策略
- 手动选择优先充电/负载均衡/优先放电后会保持，不再被自动规则立刻改回。
- 只有低电量规则触发，或外接设备从阈值以下升到阈值以上时才自动回切。
- 优先充电仍受“最大充电电量”上限约束，不会绕过用户设置。

## 更新与兼容
- 更新清单改读 `Apps/BarControl/docs/updates.json`，不再回退到限流的 GitHub API。
- 全量 159 个测试通过。
