# Bar Control 0.40.7

## 新用户适配
- 服务页只显示本机真实存在的服务；全新电脑不再出现未安装的条目，也不会显示空的 0/0 行。
- AI coding 只在检测到真实账户或中转配置时出现，不再把空的 `~/.codex` 目录当作数据。
- 新电脑默认只保留功率、剪贴板和键盘锁；剪贴板从 0 条开始，键盘锁显示待授权。
- 新增新电脑首次安装预览图，展示无个人服务、无 AI 账户、无外接设备时的界面。

## 随航与快捷指令
- 普通启动随航管家改为无窗口连接：iPad 快捷指令无需修改脚本即可连接，连完自动退出，不再残留设置窗口挡住画面。
- 已连接时只确认状态，不会反向断开；需要设置时使用 `--settings` 或启动时按住 Option。

## 验证
- 新增服务发现测试：干净环境下内置模板全部隐藏，存在 LaunchAgent plist 或日志目录时才显示。
- 全量 157 个测试通过。
