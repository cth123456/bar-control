# Bar Control 0.40.6

## 新增与改进
- 更新并整理 Bar Control Touch Bar、AI coding、能源流、电源策略、整机监控、亮度和菜单栏功能。
- 改进设置窗口与组件定制体验，保留用户保存的 Touch Bar 模块布局。
- 更新与关于页面支持发现新版本及校验安装包后的一键更新。
- GitHub 首页补充软件简介、快速下载入口，并说明内置功能与可选独立组件。

## 安装与模块
- `Bar Control.app` 是必需的主 App；其 Touch Bar 与菜单栏功能模块随主 App 一起安装，无需分别下载。
- `随航管家.app` 是可选的独立伴侣 App，可从源码单独构建和安装；使用随航需满足 Apple 的设备兼容与账户条件。
- 优先放电 helper 已包含在 Bar Control App 包内，只在用户主动启用该功能并同意管理员授权时安装。
- 常规使用不需要 BetterTouchTool、Xcode 或管理员组件。

## 已知限制
- 需要带实体 Touch Bar 的 MacBook Pro 和 macOS 13 或更高版本。
- Touch Bar 亮度、常驻和部分供电控制使用 macOS 私有接口，系统或固件更新可能影响可用性。
- CHIE 放电控制取决于机型与固件；不可用时安全退回充电上限策略。
